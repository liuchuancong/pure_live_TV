# 背景设置页面重构方案（lib/features/wallpaper）

## 现状问题
- 当前 `wallpaper_page.dart`（716 行）用两层 `TvTabBar`（6 源 + wallhaven 19 分类）+ 一次性 240 项网格，整页 `setState` 频繁重建 → 卡顿。
- 没有 API 随机壁纸源；没有全屏预览；分类浏览只有 tabbar 一种形态。
- 参考项目（C:\Users\m1779\Downloads\pure_live_TV-main\lib\modules\wallpaper + common/consts/app_consts.dart）提供了 19 个随机壁纸 API 源和取图逻辑（jkapi 需 apiKey+JSON 解析、alcy 按分类路径、其余直连下载）。

## 新页面结构（全部走设置页同款列表组件 TvSettingsRow/Card/GroupTitle）

1. **wallpaper_page.dart（重写）**——设置式列表首页：
   - 「壁纸库」分组：`backgroundCatalogProvider` 每个源一行（名称 + “N 张 · M 个分类”副标题），点击进画廊页。加载中只显示占位行，不阻塞整页。
   - 「随机壁纸 API」分组：每个 API 一行（名称 + 域名副标题），点击进全屏预览页（API 模式）。
   - 「显示设置」分组：填充模式（7 种 BoxFit 选择行）、遮罩浓度（预设档位选择行）、清除背景（动作行）。

2. **wallpaper_gallery_page.dart（新）**——按源进入：有分类的源显示**分类竖排列表**（名称+数量，替代 tabbar）；单分类源直接显示网格。

3. **wallpaper_items_page.dart（新）**——某分类的图片网格（5 列、cacheExtent 优化、缩略图仍走 wsrv.nl 代理），点击图片/视频进全屏预览；渐变色点击直接应用（toast 提示）。

4. **wallpaper_preview_page.dart（新）**——全屏预览：
   - 页面级 `Focus(onKeyEvent)`：←→ 上一个/下一个（API 模式则 = 换一张），↓ 可下移到底部操作条，返回键退出。
   - 底部操作条（DpadFocusable chips）：上一个/下一个 或 换一张、填充模式、遮罩、**设为背景**。
   - 图片按当前 boxFit 全屏渲染；视频显示封面（设为背景后由背景层播放）；渐变全屏渲染。
   - 返回焦点对齐：项目已有 `TvFocusRestorer`（TvScaffold 内置）在 pop 时自动恢复到进入前聚焦的行/格子，无需额外处理。

5. **wallpaper_api_source.dart（新）**——移植参考项目的源定义与取图：
   - 19 个源（去掉“不使用”）：bing 随机、小晓API、jkapi 系列 8 个（含 apiKey，`?type=json&apiKey=` 取 `image_url|content`）、mtyqx、alcy（`t.alcy.cc/` + 随机分类路径，修复参考项目中永不匹配的 bug）、picsum、dmoe、loliApi、搏天 3 个、catvod。
   - `fetchRandomImage()` 用项目已有 Dio 下载字节（桌面 UA、超时），预览页确认后再应用。

## 数据/控制器改动
- `background_controller.dart`：新增 `setNetworkImageBytes(bytes)`（base64 存 `currentBoxImageBase64`、清空 URL）；`setNetworkImage(url)` 反向清空 base64，保证两字段永远一致；`_updateState` 改为**值变化才写 Hive**（避免大 base64 在每次调遮罩/填充时重复写入——卡顿来源之一）。
- `tv_scaffold.dart` `_resolveImage()`：networkImage 源优先用 base64（新 setter 保证一致性），否则走 URL。
- 路由：`app_routes.dart`/`app_router.dart` 新增 `/wallpaper_gallery`、`/wallpaper_items`、`/wallpaper_preview`（extra 传 args 对象，仿 SearchResultArgs 模式）。
- i18n：zh.json / en.json / locale_helper.dart 增加 壁纸库、随机壁纸API、填充模式 7 档、遮罩、换一张、上一个/下一个、设为背景、预览提示等 key；复用已有 background_* key。
